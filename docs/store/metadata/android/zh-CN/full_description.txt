RuleBook 是一本印度尼西亚法律法规的口袋指南:包含法规目录、权益与罚则计算器、紧急情况 SOP 以及合规检查清单。

核心功能:
✓ 法规目录:交通、劳动、消费者保护、网络/ITE、财产、民事与家庭、一般刑法
✓ 每条法规均附摘要、法律依据、处罚/罚款和主要权利
✓ 计算器:加班费、遣散费、按比例 THR(节日津贴)、交通罚款模拟、ITE 处罚
✓ 附官方热线电话的紧急情况分步 SOP
✓ 自我合规审查清单
✓ 收藏常用法规并添加个人笔记
✓ 100% 离线、无广告、无需账号

为什么选择 RuleBook?
需要时,法规和权利往往很难找到。RuleBook 将法律依据、处罚和实用步骤集中在一个应用中,无需联网随时可查。

注意:RuleBook 是实用的法律科普,并非法律意见。
