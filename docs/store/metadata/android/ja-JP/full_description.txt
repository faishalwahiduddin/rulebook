RuleBookは、インドネシアの法令・規則をまとめたポケットガイドです。法令カタログ、権利や罰則の計算機、緊急時のSOP、コンプライアンスのチェックリストを収録しています。

主な機能:
✓ 法令カタログ:交通、労働、消費者保護、サイバー/ITE、不動産、民事・家族、一般刑法
✓ すべての法令に要約、法的根拠、制裁・罰金、主な権利を掲載
✓ 計算機:残業代、退職金、日割りTHR(宗教祝日手当)、交通違反の罰金シミュレーション、ITE法の制裁
✓ 公式ホットライン番号付きの緊急時SOPをステップごとに表示
✓ 自己コンプライアンス監査チェックリスト
✓ お気に入りの法令の保存と個人メモの追加
✓ 100%オフライン、広告なし、アカウント不要

RuleBookを選ぶ理由
必要なときに限って、ルールや権利は見つけにくいものです。RuleBookは法的根拠、罰則、実践的な手順を1つのアプリにまとめ、インターネットなしでいつでも開けます。

ご注意:RuleBookは実用的な法教育であり、法的助言ではありません。

プライバシー:
検索内容やメモは端末内にのみ保存され、サーバーに送信されることはありません。
