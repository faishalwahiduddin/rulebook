RuleBook دليل جيبي للقوانين واللوائح الإندونيسية: فهرس للقواعد، وحاسبات للحقوق والغرامات، وإجراءات تشغيل قياسية (SOP) للطوارئ، وقوائم تحقق للامتثال.

أبرز المزايا:
✓ فهرس القواعد: المرور، العمل، حماية المستهلك، الجرائم الإلكترونية/ITE، العقارات، القانون المدني والأسري، والقانون الجنائي العام
✓ ملخص والأساس القانوني والعقوبات/الغرامات وأهم الحقوق لكل قاعدة
✓ حاسبات: العمل الإضافي، مكافأة نهاية الخدمة، THR (علاوة العيد) بالتناسب، محاكاة غرامات المرور، وعقوبات ITE
✓ إجراءات طوارئ خطوة بخطوة مع أرقام الخطوط الساخنة الرسمية
✓ قائمة تدقيق للامتثال الذاتي
✓ حفظ القواعد المفضلة وإضافة ملاحظات شخصية
✓ يعمل 100% دون إنترنت، بلا إعلانات، وبلا حساب

لماذا RuleBook؟
يصعب العثور على القواعد والحقوق عند الحاجة إليها. يجمع RuleBook الأساس القانوني والعقوبات والخطوات العملية في تطبيق واحد تفتحه في أي وقت دون إنترنت.

تنبيه: RuleBook تثقيف قانوني عملي وليس استشارة قانونية.

الخصوصية:
تبقى عمليات البحث والملاحظات على جهازك ولا تُرسل إلى أي خادم.
