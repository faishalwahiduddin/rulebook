Kebijakan Privasi (Privacy Policy)

Terakhir diperbarui: 2026-10-04

Kebijakan Privasi ini menjelaskan bagaimana kami mengelola informasi Anda pada aplikasi RuleBook (tersedia di rulebook.faishal.id).

1. Pengumpulan Informasi

Kami sangat menghargai privasi Anda. Aplikasi RuleBook dirancang sepenuhnya sebagai aplikasi offline-first dan privat. Kami tidak mengumpulkan, menyimpan di server, melacak, mengirimkan, atau membagikan data pribadi Anda ke server pihak mana pun. Semua yang Anda masukkan tetap berada di perangkat Anda.

2. Penyimpanan Data Lokal

Semua catatan, checklist, dan konfigurasi Anda disimpan secara lokal pada perangkat Anda (penyimpanan lokal browser atau database lokal aplikasi). Data ini sepenuhnya berada di bawah kendali Anda dan akan terhapus jika Anda membersihkan data aplikasi atau cache penyimpanan lokal browser.

3. Layanan Pihak Ketiga

Jujur kami sampaikan: di dalam aplikasi tidak ada SDK analitik pihak ketiga, tidak ada iklan pelacak, dan tidak ada pelacak apa pun. Namun halaman web (landing page) ini memuat font dari Google Fonts dan gambar bendera dari flagcdn.com; kedua layanan tersebut dapat mencatat alamat IP Anda saat halaman dimuat — ini di luar kendali kami. Kami sendiri tidak memasang piksel pelacakan atau skrip analitik apa pun di halaman ini.

4. Cookie

Kami tidak menempatkan cookie milik sendiri pada halaman ini dan tidak menggunakan cookie untuk analitik atau periklanan. Browser atau CDN pihak ketiga di atas mungkin menerapkan mekanisme teknisnya sendiri sesuai kebijakan mereka.

5. Dasar Hukum

Sejauh peraturan perlindungan data (termasuk GDPR Pasal 6 dan UU Pelindungan Data Pribadi Indonesia) berlaku: karena kami tidak memproses data pribadi di server, tidak ada pemrosesan yang memerlukan dasar hukum di sisi kami. Setiap pemrosesan yang Anda lakukan di perangkat Anda sendiri terjadi atas dasar persetujuan dan kepentingan sah Anda menggunakan aplikasi (GDPR Pasal 6 ayat 1 huruf a dan f). Log IP oleh Google Fonts/flagcdn.com tunduk pada kebijakan masing-masing penyedia.

6. Retensi Data

Kami tidak menyimpan data Anda di server sehingga tidak ada periode retensi di sisi kami. Data lokal di perangkat Anda tersimpan selama Anda menyimpannya dan terhapus saat Anda menghapusnya.

7. Hak Anda

Anda berhak mengakses, memperbaiki, dan menghapus data Anda langsung di perangkat (cukup hapus data aplikasi). Untuk pertanyaan atau permintaan terkait hak subjek data (akses, penghapusan, keberatan, portabilitas) menurut GDPR/UU PDP, hubungi kami di support@faishal.id — kami akan menanggapi dalam waktu yang wajar.

8. Perubahan Kebijakan

Kami dapat memperbarui Kebijakan Privasi ini sewaktu-waktu. Setiap perubahan akan dipublikasikan langsung pada halaman ini beserta tanggal revisinya. Versi ini berlaku sejak 2026-10-04.

9. Hubungi Kami

Jika Anda memiliki pertanyaan tentang Kebijakan Privasi ini, silakan hubungi kami di support@faishal.id.
