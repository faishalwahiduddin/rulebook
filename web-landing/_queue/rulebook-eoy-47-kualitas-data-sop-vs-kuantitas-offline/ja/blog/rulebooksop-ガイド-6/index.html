FAQ

Can I log SOP offline?

Yes. RuleBook stores data on-device; daily entries don’t need the internet.

Do I need an account first?

No. Start without login. Periodic exports cover most backup needs.

How many fields for SOP?

Three at first: time, status, blocker. Add more only after 14 steady days.

What if I miss a few days?

Don’t wipe history. Resume today and note the blocker so the pattern stays visible.
