# App Store Submission — RuleBook (`id.faishal.rulebook`)

Companion to the Play drafts: values for **App Store Connect**. Metadata lives in
`metadata/ios/<locale>/` (fastlane `deliver` layout, locales: id, en-US, ar-SA, ja, zh-Hans, es-ES).

## App Store Connect settings

| Field | Value |
|-------|-------|
| Bundle ID | `id.faishal.rulebook` (already set in `ios/Runner.xcodeproj`) |
| SKU | `rulebook-ios` |
| Primary language | Indonesian (id) |
| Primary category | **REFERENCE** |
| Price | Free |
| Age rating | 4+ (no objectionable content) |
| Export compliance | `ITSAppUsesNonExemptEncryption = false` (already in Info.plist — no yearly prompt) |
| Sign-in required | No — provide "no account needed" note in App Review notes |
| Privacy policy URL | https://rulebook.faishal.id/privacy |

## App Privacy (nutrition labels)

| Item | Answer |
|------|--------|
| Data collection | **Data Not Collected** (all data stays on-device) |
| — | App accesses no sensitive data |

## Screenshot requirements (per locale)

Same 4-slide continuous-panorama design as Play (shared `screenshots/art.js`);
generated by `tools/gen-store-scaffold/capture-slides.mjs` into
`metadata/ios-screenshots/<locale>/` (deliver infers device class from pixel size).

| Device class | Size | Required | File prefix |
|--------------|------|----------|-------------|
| iPhone 6.7"/6.9" | 1290×2796 | ✅ min 1 (up to 10; ASC scales smaller iPhones from it) | `iphone69-` |
| iPad 13" | 2064×2752 | ✅ (iPad supported by default in these Flutter apps) | `ipad13-` |

```bash
node tools/gen-store-scaffold/capture-slides.mjs rulebook --only=iphone69
node tools/gen-store-scaffold/capture-slides.mjs rulebook --only=ipad13
node tools/gen-store-scaffold/verify-screenshots.mjs rulebook
```

## Submission checklist
- [ ] Apple Developer Program membership active
- [ ] App ID `id.faishal.rulebook` registered + signing via Xcode automatic signing
- [ ] `flutter build ipa --release` succeeds
- [ ] Metadata reviewed (`metadata/ios/`) — **non-English locales need native-speaker review** (ar-SA, ja, zh-Hans, es-ES)
- [ ] iPhone 6.9" screenshots (1290×2796) in `metadata/ios-screenshots/<locale>/` — 4 per locale
- [ ] iPad 13" screenshots (2064×2752) in `metadata/ios-screenshots/<locale>/` — 4 per locale
- [ ] App Privacy questionnaire: Data Not Collected
- [ ] Privacy policy live at https://rulebook.faishal.id/privacy
- [ ] TestFlight internal build → App Review submission

## Fastlane upload (later)
```bash
cd rulebook && fastlane deliver --metadata_path store/metadata/ios \
  --screenshots_path store/metadata/ios-screenshots \
  --ipa build/ios/ipa/rulebook.ipa
```
